# Contributing to WCCC

Thank you for your interest in WooCommerce Card-to-Card (WCCC).

This repository contains an early public reference snapshot of WCCC, version 1.0.65.

## Project Scope

The public repository represents an early project snapshot and is not the complete or latest development version.

Contributions should be limited to the code and documentation available in this repository.

## Reporting Issues

When reporting an issue, please include:

- A clear description of the problem.
- Steps to reproduce the issue, when applicable.
- Expected and actual behavior.
- Relevant screenshots or error messages.
- Environment details, when relevant.

Do not include real customer information, payment receipts, bank card numbers, credentials, API keys, or production logs.

## Pull Requests

Before submitting a pull request:

1. Keep changes focused and limited in scope.
2. Explain the reason for the proposed change.
3. Describe any relevant testing performed.
4. Avoid introducing unrelated modifications.
5. Ensure third-party code and assets retain their original license notices.

## Development Notes

This repository includes a React and TypeScript-based interface prototype and WooCommerce-oriented frontend assets.

It does not contain the complete PHP implementation required for a fully operational WooCommerce plugin.

Please take this limitation into account when proposing changes or testing the project.
